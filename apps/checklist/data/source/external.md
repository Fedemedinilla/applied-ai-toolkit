# External checks (EXT)

Passive: requests any visitor's browser makes, public DNS answers and public lookup tools. No authorization needed. Rewritten in English from the audit method's external list; the commands and the source references are left out.

| ID | Title | Question | Where | Pass when | If it fails | Do not touch | Priority | Area | Platforms | Needs | Access |
|---|---|---|---|---|---|---|---|---|---|---|---|
| EXT-01 | HTTP security headers | Does the site tell the browser how to protect visitors? | Response headers of the home and one inner page | HSTS with a max-age of at least 15552000 and nosniff are present; Referrer-Policy and frame protection are set | Add them at the server or the CDN; start a Content-Security-Policy in Report-Only mode | A strict Content-Security-Policy breaks page builders that inline their scripts | High | security | cms static | - | passive |
| EXT-02 | Version disclosure | Can anyone see which CMS and plugin versions the site runs? | HTML, the feed, readme.html and ?ver= parameters | No generator tag with a version; readme.html answers 403 or 404; no ?ver= reveals a plugin with a known flaw | Hide the generator tag, block readme.html and update what is exposed | - | Medium | security | cms | - | passive |
| EXT-03 | User enumeration | Can anyone list the account names? | The REST users endpoint and author archives | The REST API lists no users to anonymous visitors; ?author=N does not reveal a login name | Block enumeration through REST and through author archives | Do not disable the whole REST API: the editor needs it | High | security | wp | - | passive |
| EXT-04 | Sensitive files exposed | Are private files reachable by anyone? | A fixed list at the site root: config backups, .env, .git/config, debug.log, database dumps, phpinfo pages | Every path answers 403 or 404 | Remove or deny them; a config backup that answered 200 opens the incident runbook | - | Critical | security | all | - | passive |
| EXT-05 | SPF, DKIM, DMARC and MX | Can someone send mail pretending to be the domain? | TXT and MX records of the domain | SPF present without +all; DMARC present (p=none with rua to start measuring); DKIM valid | Publish SPF with ~all and DMARC p=none with rua, then move to quarantine | Do not change MX without knowing who receives the mail | High | security | all | own-mail | passive |
| EXT-06 | Dangling CNAME | Are there abandoned subdomains someone could take over? | DNS and certificate transparency logs | No CNAME points at an unclaimed resource | Delete the CNAME or claim the resource | - | High | security | all | - | passive |
| EXT-07 | TLS and certificate expiry | Is the padlock valid and not about to expire? | Port 443 | Full chain; expires in more than 15 days; no TLS 1.0 or 1.1 | Renew or install the full chain; require TLS 1.2 or newer | - | High | security | all | - | passive |
| EXT-08 | Field Core Web Vitals on mobile | How fast do real visitors see the page on a phone? | PageSpeed Insights field data (Chrome UX Report), mobile | LCP under 2.5 s, INP under 200 ms and CLS under 0.1 in field data | Follow the speed list (VEL) | - | High | speed | all | - | passive |
| EXT-09 | Server version disclosure | Does the server announce its software and version? | The Server and X-Powered-By headers | No exact version in either header | Ask the host to hide versions | - | Low | security | cms | - | passive |
| EXT-10 | Directory listing | Can folders be browsed as a list? | Upload, plugin and include folders | No folder lists its contents | Turn directory indexes off, or add an empty index file per folder | - | Medium | security | cms | - | passive |
| EXT-11 | XML-RPC and pingback | Is the old remote publishing endpoint open? | /xmlrpc.php and the X-Pingback header | xmlrpc.php answers 403 or 404, or its use is known and protected | Block it at the server or with the security plugin, unless something uses it | Do not block it while Jetpack or the mobile app uses it | Medium | security | wp | - | passive |
| EXT-12 | Cloaking and conditional redirects | Does the site show something else to Google or to phones? | The home fetched with a desktop, a crawler and a phone user agent | Same content for all three, with differences of layout only | Treat it as a sign of compromise and open the incident tab | - | Critical | security | all | - | passive |
| EXT-13 | Domain expiry and registrar lock | Is the domain about to expire or unlocked? | RDAP, or the registry's own lookup where there is no RDAP | Expires in more than 60 days; auto-renewal on or a named person responsible | Renew; turn on auto-renewal and two-factor at the registrar | - | High | security | all | - | passive |
| EXT-14 | Old copies and staging exposed | Are forgotten old copies of the site published? | /old/, /backup/ and similar paths; staging, dev and test subdomains; a site: search | No old copy answers or is indexed | Delete or password-protect them; add noindex; request removal | - | High | security | all | - | passive |
| EXT-15 | Open redirect parameters | Could a link on the site send visitors anywhere? | redirect, url, next and return parameters in the HTML | No open redirect parameters, or they validate the target | Validate the target on the server against an allow list | Testing the redirect is active: only with authorization | Medium | security | all | - | passive |
| EXT-16 | Mixed content | Does any part of the page load without the padlock? | HTML of the home and one inner page | Zero http:// resources on https:// pages | Switch them to https://; on a CMS, search and replace in the database after a backup | Search and replace without a backup | Medium | security | all | - | passive |
| EXT-17 | HTTPS and canonical host | Does every address land on one host with the padlock? | The http, https, apex and www responses | http redirects to https; one of apex or www redirects to the other | Configure the redirect at the host | No HSTS preload until every subdomain has HTTPS | High | security | all | - | passive |
| EXT-18 | HTTP/2 or HTTP/3 and compression | Does the server use the fast protocols? | Status line and headers | HTTP/2 at least, and compression on | Turn them on at the host or put a CDN in front | - | Medium | speed | all | - | passive |
| EXT-19 | Cache and CDN headers | Is a cache or CDN layer working? | Cache-Control and cache status headers, on two loads in a row | The second load shows a cache hit, or Cache-Control has a reasonable max-age | Turn on page caching (VEL-05) | Do not cache pages with sessions or form tokens | Medium | speed | cms static | - | passive |
| EXT-20 | Time to first byte from outside | How long does the server take to start answering? | Time to first byte of the home, three runs | Median under 0.8 s | Work on hosting and cache (VEL-01) | - | High | speed | all | - | passive |
| EXT-21 | Page weight and third parties (lab) | How heavy is the page, and how much of it comes from third parties? | A Lighthouse lab run on mobile | Weight and the largest resources are measured and recorded; there is no universal threshold | Follow VEL-02 and VEL-10 | - | Medium | speed | all | - | passive |
| EXT-22 | Visible plugins against vulnerability databases | Does any visible plugin have a known flaw? | Plugin and theme paths with ?ver= in the HTML | No visible plugin with an unpatched known flaw | Update or replace it (needs access: INT-06) | Check each vulnerability database's terms before commercial use | High | security | wp | - | passive |
| EXT-23 | Safe Browsing and blocklists | Do Google or mail blocklists flag the site? | Safe Browsing and domain blocklists | No warning and no listing | Treat it as an incident; request a review afterwards | - | Critical | security | all | - | passive |
| EXT-24 | Search spam signals | Does Google show pages on the site that are not the owner's? | site: search results | No results foreign to the site | Treat it as an incident; clean up and request removal | - | Critical | security | all | - | passive |
| EXT-25 | Privacy policy | Does the site publish a privacy policy for the data its forms collect? | Links on the home and in the footer | A privacy policy page is linked and answers 200 | Publish one and link it next to every form | - | Medium | security | all | forms | passive |
