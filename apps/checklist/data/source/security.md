# Hardening (SEG)

What changes during execution to close what the diagnosis found: after the backup and the updates, before the speed work. Active: needs authorization and access. Each measure names its trap. Rewritten in English from the audit method's hardening list.

| ID | Title | Question | Where | Pass when | If it fails | Do not touch | Priority | Area | Platforms | Needs | Access |
|---|---|---|---|---|---|---|---|---|---|---|---|
| SEG-01 | Incident response | What happens if the site is compromised? | Every layer | Zero indicators in a second full pass; external and internal scanners clean | Iterate, or hand over to a cleanup service | The credential rotation order (SEG-02) | Critical | security | cms | - | authorized |
| SEG-02 | Credential rotation order | In what order are the credentials changed? | CMS, hosting, database, tokens and integrations | Everything rotated with the environment inert, and logged with dates | Repeat with the site isolated | Rotating salts live without notice; rotating before isolating the site | Critical | security | cms | - | authorized |
| SEG-03 | Firewall layer | Is there a filter in front of the site? | CDN firewall, security plugin or the host's web firewall | One layer active for the site's risk | Turn on a CDN firewall or the plugin firewall | CDN script rewriting and auto-minify break builder scripts; a plugin firewall starts in learning mode | Medium | security | cms static | - | authorized |
| SEG-04 | Named accounts and least privilege | Does every person have their own account with the role they need? | Users | One user per person; administrators only for those who administer; no former contractor keeps access | Create accounts, reassign content, lower roles | Do not delete a shared account that authors content: change its password and reassign | High | security | wp | - | authorized |
| SEG-05 | Second factor for administrators | Do administrators need more than a password? | The security plugin's sign-in settings | Every administrator enrolled with an authenticator app and recovery codes stored; then required for the role | Enrol people one at a time | Making it required before everyone is enrolled | Critical | security | wp | - | authorized |
| SEG-06 | Disable file editing | Can code be edited from the dashboard? | wp-config.php | The theme and plugin editors are gone from the dashboard | Add DISALLOW_FILE_EDIT with a copy of the file | A syntax error gives a blank page | High | security | wp | - | authorized |
| SEG-07 | XML-RPC blocked when unused | Is XML-RPC closed? | .htaccess or the security plugin | xmlrpc.php answers 403 from outside (EXT-11) | Block it | Jetpack and the mobile app use it: confirm first | Medium | security | wp | - | authorized |
| SEG-08 | REST user enumeration limited | Can the API list users? | The REST users endpoint | EXT-03 passes from outside | Turn on the security plugin's option or add a small filter | Do not disable the whole REST API | High | security | wp | - | authorized |
| SEG-09 | Security headers | Does the browser get the security instructions? | Server config, CDN or security plugin | EXT-01 passes; the Content-Security-Policy ran in Report-Only with no console errors first | Add one header at a time and verify | HSTS preload before every subdomain has HTTPS; a strict policy with page builders | High | security | cms static | - | authorized |
| SEG-10 | Update policy | How and when are updates applied? | The updates screen and auto-update settings | Security and minor updates current; major updates tested in staging | Apply them with a backup | Major updates in production | High | security | cms | - | authorized |
| SEG-11 | 3-2-1 backups with a tested restore | Are there copies in three places, and has a restore been tested? | The backup plugin and the host's backups | A copy with the database on the host and off it; a test restore recorded | Configure and test | Restoring over production as a test | Critical | security | cms | - | authorized |
| SEG-12 | Minimum monitoring | Will anyone notice if something happens? | Uptime monitor, security alerts, search console, Safe Browsing, DMARC reports and expiry dates | All six signals configured to a mailbox someone reads | Configure them | - | High | security | all | - | authorized |
| SEG-13 | Former contractors and migration plugins | Does a former contractor still have access? | Users, hosting, external accounts and plugins | No out-of-date third-party access; no export or migration plugin installed | Remove access; uninstall the plugins | Do not delete the user who authors the content: reassign it | High | security | all | - | authorized |
| SEG-14 | Mail authentication hardening | Is the domain's mail protected against spoofing? | DNS | SPF without +all; DKIM verified; DMARC p=none with rua, then quarantine after a month of clean reports | Publish or correct the records | Do not change MX; no p=reject without a month of reports | High | security | all | own-mail | authorized |
| SEG-15 | Sign-in brute force protection | Can passwords be guessed without limit? | The security plugin or the host's firewall | An attempt limit is on; logged attempts get 403 or 429 | Turn it on | Locking out your own address: add the exception | High | security | wp | - | authorized |
| SEG-16 | Salt rotation with notice | Were the internal keys changed after the incident? | The salts in wp-config.php | New salts, with a date; users told they must sign in again | Rotate them | Rotating without notice signs everyone out at once | Medium | security | wp | - | authorized |
| SEG-17 | No PHP execution in uploads | Could an uploaded file run as code? | uploads/.htaccess | A .php file placed in uploads answers 403 (tested in staging) | Add the rule | On Nginx the rule goes in the server config | High | security | wp | - | authorized |
| SEG-18 | Directory listing off | Can folders no longer be listed? | The root .htaccess | EXT-10 passes from outside | Add Options -Indexes | A syntax error returns 500 | Medium | security | cms | - | authorized |
| SEG-19 | Hidden version and readme | Is the version no longer visible from outside? | Child theme or security plugin; readme.html | EXT-02 passes | Remove the generator tag and block readme.html | Editing the parent theme | Low | security | wp | - | authorized |
