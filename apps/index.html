Applied AI Toolkit demos

Each demo is an app from the repository, built from its own folder and served as static files. Nothing you type leaves your device.

Demos

  • Caja

    An offline cash book that reads a Spanish sentence such as "vendí 5 tortas a 8000" and asks when the amount has two readings.

    Interfaz en español · builds on amount-parser

  • Receipt

    Edit an order, including names with emoji and right-to-left text, and download its delivery note as a PDF built in the tab.

    Interfaz en español · builds on pdf-receipt

  • Replay Lab

    Play a seeded dice tournament, export the run, edit the file and watch its hash fail on import, or run 1,000 seeds in a worker.

    English · builds on deterministic-sim

  • Site checklist

    Work through a website audit check by check, with the order of the steps enforced, and export the before and after report.

    English · reads the run format of site-check

The apps that need a server (the chat widget, the writer, the salon assistant and push-lab) are not published here. Their READMEs explain how to run them.

Source, tests and design notes: github.com/Fedemedinilla/applied-ai-toolkit. All data in the demos is fictional.
